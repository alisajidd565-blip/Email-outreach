# QZI Rate Card Generator

One file: `QZI-Rate-Card-Generator.html`. Works offline. Nothing to install except a shortcut.

## Put it on your PC (2 minutes, once)
1. Download `QZI-Rate-Card-Generator.html` and move it to a folder you keep, e.g. `Documents\QZI Labs\`.
   (Don't leave it in Downloads: if the file moves, the shortcut breaks.)
2. Double-click it. It opens in Chrome or Edge.
3. Make it an app with its own window and desktop icon:
   - **Chrome:** menu (⋮) → Cast, save and share → **Create shortcut…** → tick **Open as window** → Create.
   - **Edge:** menu (…) → More tools → **Pin to taskbar** (or Pin to Start).
   From now on, open it from the desktop / taskbar icon.

## Use it
- Left side: type prices, names and features. The card on the right updates as you type.
- **Save as PDF**: opens the print window. Choose "Save as PDF", paper A4. If the black contact box comes out
  white, tick "Background graphics" under More settings.
- **Copy as email bullets**: copies the card as plain text, ready to paste into Gmail.
- **Save this card**: keep a named version (e.g. one per client). Open it again from "Open a saved card".
- **Backup to file**: saves every card to a .json file. Do this now and then: saved cards live inside the browser,
  and clearing browser data deletes them. **Load from file** brings them back (also how to move cards to another PC).
- **Reset to QZI standard card**: the current rates (Nov 2026: single rates $25–$899, store film $800;
  Presence $990, Growth $1,990, Master $4,900).
- Plans: put a "Rate-card value" higher than the price and the card shows the crossed-out value and "You save".
- Currency: USD, EUR, GBP, PKR, AED (changes the symbol only, not the amounts).
